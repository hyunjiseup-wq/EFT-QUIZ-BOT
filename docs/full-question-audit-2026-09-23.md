## 발견 사항

### 1. Q144 — 지문과 해설에서 구 직접 처치 조건 제거 필요

현재 지문은 “직접 처치한 상대 진영의 도그태그”, 해설도 직접 처치를 강조한다.
공식 1.1.0.0 Fixes는 명예의 전당 보너스의 본인 직접 처치 요건을 제거했다고 명시한다.
Q338에는 이미 이 변경이 반영되어 있어 두 문항을 함께 접하면 조건을 다르게 배우게 된다.

정답인 Hall of Fame 자체는 바꿀 필요가 없다. 직접 처치한 도그태그도 사용할 수 있으므로
문장 전체를 거짓으로 판정하는 것이 아니라, **불필요한 요건을 강조하는 오래된 설명**을 고치는 것이 맞다.

권고 지문: “상대 진영 PMC의 도그태그를 전시해 전투 스킬 성장 보너스를 받는 시설은?”
권고 해설: “홀 오브 페임은 상대 진영 PMC 도그태그 전시로 전투 스킬 성장 보너스를 제공합니다.
1.1.0에서 본인이 직접 처치해야 한다는 조건은 제거됐습니다.”

근거: [공식 1.1.0.0 Fixes](https://telegra.ph/Patch-1100-08-03).
영문 [Hideout](https://escapefromtarkov.fandom.com/wiki/Hideout)와
[Character skills](https://escapefromtarkov.fandom.com/wiki/Character_skills)의 검색본에는
구 조건이 남아 있어 공식 변경을 우선해야 한다.

### 2. Q469·471 — 도그태그 종류를 명시하는 것이 안전

일본어 [케이스 표](https://wikiwiki.jp/eft/ケース)는 문서 케이스와 S I C C의 수납 품목 차이를 뒷받침한다.
다만 [S I C C 개별 페이지](https://wikiwiki.jp/eft/S%20I%20C%20C%20organizational%20pouch)는
2026년 2월 기준 엔딩 도그태그 수납 예외를 따로 기록한다.
이 예외가 9월 현재도 남아 있다고 확정하지 않는다.

- Q469: 정답 보기와 해설을 “일반 PMC 도그태그”로 좁히고, 해설의 S I C C 추천도 같은 범위로 한정.
- Q471: 정답을 “일반 PMC 도그태그와 금 해골 반지”로 명시.
- 현재 정답이 뒤집혔다고 확인된 것은 아니다. 예외 종류까지 포괄하는 표현을 피하기 위한 권고다.

### 3. Q410·429 — 과거 위키 버그 기록은 현행 게임 규칙 검증이 아님

현재 지문은 각각 “과거 Achievements 위키”, “과거 Intellect 위키”를 묻도록 제한돼 있어
현재 버그라고 직접 단정하지는 않는다. 그러나 기록 시점·판본이 지문에 없고, 실제 게임 지식보다
어느 검색 수집본에 어떤 문장이 있었는지를 묻게 된다. 현행 지식 이벤트라면 보류 또는 안정된
기능 문항으로 교체하는 편이 낫다. 최신 버그 존재 여부는 미확인이다. 이번에는 수정하지 않았다.

### 4. 기존 보류 4문항은 재활성화 근거 없음

Q95(미니맵), Q102(킬피드)는 최신 본편 UI를 직접 확인해야 한다.
Q225·226(상인 매입 배율)은 1.1.0의 평균 가격 조정만으로 상인별 현재 배율을 계산할 수 없다.
기존 `enabled: false`를 유지했다.
